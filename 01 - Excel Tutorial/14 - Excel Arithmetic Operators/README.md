
# 14 - Excel Arithmetic Operators (Operator Aritmatika)

Materi mengenai dasar-dasar operator matematika yang digunakan untuk melakukan perhitungan angka di Excel.

## Apa itu Arithmetic Operators?

* **Definisi**: Simbol-simbol matematika dasar yang digunakan untuk melakukan operasi hitung (penjumlahan, pengurangan, perkalian, pembagian, dan pangkat) di dalam rumus Excel.

## Daftar Operator Aritmatika di Excel

Berikut adalah simbol-simbol operator yang wajib dihafal:

| Operasi                              | Simbol / Tanda | Contoh Penulisan Rumus |
| :----------------------------------- | :------------: | :--------------------- |
| **Penjumlahan** (Addition)     |     `+`     | `=A10 + B10`         |
| **Pengurangan** (Subtraction)  |     `-`     | `=A10 - B10`         |
| **Perkalian** (Multiplication) |     `*`     | `=A10 * B10`         |
| **Pembagian** (Division)       |     `/`     | `=A10 / B10`         |
| **Pangkat** (Exponentiation)   |     `^`     | `=A10 ^ 2`           |

## Catatan Penting

* Semua rumus aritmatika di Excel **wajib diawali dengan tanda sama dengan (`=`)** di awal. Jika tidak pakai `=`, Excel akan membacanya sebagai teks biasa, bukan rumus perhitungan.

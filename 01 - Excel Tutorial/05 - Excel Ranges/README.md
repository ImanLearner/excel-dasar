
# 05 - Excel Ranges

Memahami konsep area sekumpulan cell (Range) dan cara membacanya di Excel.

## 1. Konsep Range

* **Definisi:** Kumpulan dari dua atau lebih cell yang dipilih/diblok secara bersamaan.
* **Sintaks Titik Dua (`:`):** Tanda `:` dibaca sebagai rentang "sampai dengan".
  * `A1:A5` -> Rentang satu kolom dari baris 1 sampai 5.
  * `A1:C1` -> Rentang satu baris dari kolom A sampai C.
  * `A1:B5` -> Rentang tabel berbentuk kotak dari pojok kiri atas (A1) hingga pojok kanan bawah (B5).

## 2. Navigasi Cepat Range (Name Box)

* Mengetik koordinat range (contoh: `A1:B5`) langsung di kotak **Name Box** (kotak di atas kolom A) lalu menekan **Enter** akan otomatis memblok seluruh range tersebut secara instan tanpa perlu drag mouse.

## 3. Latihan Praktik

1. Buka file `ranges.xlsx` di aplikasi Microsoft Excel.
2. Masukkan data angka acak di area cell `A1` sampai `B5`.
3. Klik kotak **Name Box** di pojok kiri atas, ketik `A1:B5`, lalu tekan **Enter**.
4. Amati area kotak yang otomatis terblok.


# 02 - Excel Get Started

Pengenalan formula dasar dan penggunaan tanda sama dengan (`=`) sebagai trigger kalkulator di Excel.

## 1. Konsep Dasar Formula

* **Mode Teks Biasa:** Jika mengetik `1+1` tanpa awalan tanda sama dengan, Excel menganggap nilai tersebut sebagai teks biasa dan tidak akan dihitung.
* **Mode Kalkulasi (`=`):** Tanda sama dengan (`=`) berfungsi sebagai instruksi wajib kepada Excel untuk mengeksekusi ekspresi matematika atau formula di dalam cell.
* **Formula Bar vs Nilai Tampilan:** Cell di lembar kerja akan menampilkan hasil akhir perhitungan (misal: `2`), sedangkan Formula Bar di atas akan menampilkan rumus aslinya (misal: `=1+1`).

## 2. Operator Dasar

* Simbol `+` digunakan untuk operasi penjumlahan matematika dasar.

## 3. Latihan Praktik

1. Buka file `get_started.xlsx`.
2. Di cell `A1`, ketik formula `=1+1` lalu tekan **Enter**.
3. Di cell `A2`, ketik formula `=1+2` lalu tekan **Enter**.
4. Teruskan pola tersebut hingga cell `A10` terisi dengan formula `=1+10`.
5. Perhatikan bahwa cell akan menampilkan angka `2` sampai `11`, tetapi saat cell diklik, Formula Bar tetap menampilkan rumus penjumlahan aslinya.

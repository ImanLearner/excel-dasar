
# 03 - Excel Overview

Memahami komponen antarmuka utama di sekeliling area kerja Excel untuk navigasi dan shortcut kerja cepat.

## 1. Komponen Antarmuka Utama

* **Ribbon Menu:** Deretan tab di bagian atas (Home, Insert, Page Layout, Formulas, Data, Review, View) yang berisi seluruh kumpulan tools dan fitur Excel.
* **Quick Access Toolbar (QAT):** Tombol pintas di pojok kiri atas jendela (seperti Save, Undo, Redo) untuk akses cepat fungsi yang sering digunakan.
* **Status Bar:** Baris di bagian paling bawah layar. Saat memblok sekumpulan data angka, baris ini otomatis menampilkan informasi cepat seperti **Average** (rata-rata), **Count** (jumlah data), dan **Sum** (total penjumlahan).
* **Zoom Control & View Mode:** Tombol di pojok kanan bawah untuk mengatur tingkat perbesaran layar dan tampilan halaman (Normal, Page Layout, Page Break Preview).

## 2. Latihan Praktik

1. Buka file `excel_overview.xlsx`.
2. Di kolom `A` (dari `A1` sampai `A5`), masukkan angka: `10`, `20`, `30`, `40`, `50`.
3. Blok/highlight cell `A1:A5`.
4. Perhatikan bagian **Status Bar** di bawah layar untuk melihat kalkulasi otomatis (Average, Count, Sum) tanpa perlu mengetik rumus.

# 01 - Excel Introduction

Pengenalan komponen antarmuka dasar dan anatomi lembar kerja spreadsheet di Microsoft Excel.

## 1. Anatomi Lembar Kerja (Worksheet)

* **Row (Baris):** Bagian horizontal yang diidentifikasi dengan **Angka** (1, 2, 3, dst).
* **Column (Kolom):** Bagian vertikal yang diidentifikasi dengan **Huruf** (A, B, C, dst).
* **Cell:** Titik potong/pertemuan antara kolom dan baris (contoh: `A1` artinya kolom A baris 1).
* **Range:** Kumpulan dari beberapa cell (contoh: `A1:B5` artinya area dari cell A1 sampai B5).

## 2. Navigasi Utama

* **Name Box:** Kotak di pojok kiri atas yang menampilkan koordinat cell yang sedang aktif.
* **Formula Bar:** Kolom panjang di sebelah Name Box untuk mengetik dan melihat isi asli rumus/nilai di suatu cell.
* **Sheet Tabs:** Tab di bagian bawah untuk berpindah antar halaman lembar kerja.
